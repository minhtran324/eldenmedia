# Phân hệ nghiệp vụ

Tạo thư mục people, rooms, devices, schedules, attendance, requests, reports khi triển khai từng luồng.
Mỗi phân hệ gồm components (giao diện), schemas (kiểm tra đầu vào), services (nghiệp vụ phía máy chủ).
Không đưa secret key hoặc logic quyết định quyền vào component trình duyệt.
Chưa có API ghi nghiệp vụ trong bộ khung này.
